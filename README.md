# forthparty — 오프라인 게임 맵 마킹 도구

서버 없이 내 PC에만 저장하는 개인 맵 메모장. **게임 목록 → 맵 목록 → 맵 마킹** 3단계.

## 실행 (JDK 17+)
- Windows: `run.bat`
- macOS/Linux: `./run.sh`

## 사용법
| 화면 | 동작 |
|---|---|
| 게임 목록 / 맵 목록 | Enter·더블클릭 열기, Delete 삭제, 하단 버튼으로 추가·이름 변경 |
| 게임 목록 | **마커 종류…** 게임마다 마커 종류(이름·색·모양) 설정, 다른 게임에서 가져오기 |
| 맵 목록 | **내보내기… / 가져오기…** 맵 하나를 `.fpmap` 파일 하나로 공유 (쓰인 마커 종류도 함께) |
| 맵 화면 | 우클릭: 마커 추가 (종류·이름·메모 입력) · 마커 위 우클릭: 편집/삭제 |
| | **마커 드래그: 위치 옮기기** · 마커 더블클릭: 편집 · 마우스를 올리면 메모 표시 |
| | **Ctrl+Z 되돌리기, Ctrl+Y 다시 하기** (추가·이동·편집·삭제 모두) |
| | 휠 확대 · 빈 곳 드래그 이동 · 빈 곳 더블클릭 원래 크기 |
| | 종류별 체크박스(개수 표시), 전체 표시/숨김, 마커 검색 Ctrl+F (이름·메모·종류, 초성 가능) |
| | Ctrl+L 이름 전체 표시 |
| 공통 | 오른쪽 위 **어두운 테마** (다음 실행에도 유지), 항상 위 (Ctrl+T), Esc 뒤로 |

맵 이미지는 맵 화면 오른쪽 위 **맵 이미지 지정…** 으로 넣습니다 (게임 내 지도 스크린샷 등).
마커는 색과 모양(원·사각형·삼각형·마름모·별·육각형·십자)으로 함께 구분되어, 색을 구분하기 어려워도 알아볼 수 있습니다.

## 데이터 구조
```
data/settings.properties                 프로그램 설정 (테마)
data/games/<게임>/game.properties        게임 이름 + 마커 종류 목록
data/games/<게임>/maps/<맵>.properties   맵 이름 + 마커 (종류·위치·이름·메모)
data/games/<게임>/maps/<맵>.png          맵 이미지
```
`data/` 폴더만 복사하면 백업·다른 PC 이전 끝.
